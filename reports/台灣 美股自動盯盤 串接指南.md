# 讓程式守夜、Claude 解讀、你按確認

這套系統做得出來。最省錢也最安全的做法是：程式負責 24 小時盯盤，Claude 只在條件觸發時分析新聞與盤勢，最後由你在 LINE 按確認才下單。截至 2026-10-17，台灣個人能開戶、有官方下單 API、又能交易夜盤，三項都查得到證據的海外券商只有 **Interactive Brokers（IBKR）**，代價是 IB Gateway **每週要在手機上按一次 2FA 確認**。API 最好用的 Alpaca，**查不到任何證據**顯示台灣稅籍能開實盤，所以比較實際的用法是先拿來做模擬交易。國內複委託方面，只查到**凱基與群益**有能下美股單的 API。行情方面，免費的「即時報價」多半只有 IEX 一家交易所的成交（**約占美股總成交量 3.8%**），要看完整市場每月得付約 **US$99–199**，而且個人授權只限自用。24 小時交易目前**已上線**的是券商透過 ATS（另類交易系統）提供的夜盤，時段正好落在台灣白天。交易所層級的 23/5（每週五天、每天 23 小時）**已核准**，目標 2026-12-06 上線，但還沒開跑。Claude API 若每天分析 50 次，**每月約 US$1.5–60**，看用哪個模型；混用便宜和中階模型大約 US$10。LINE 免費方案每月只有 **200 則推播**，中、高用量方案 11/1 起漲價。法規上，沒有條文處罰台灣人自行開海外帳戶，但出了糾紛，金管會幫不上忙。稅務上，美股所得屬海外所得，適用最低稅負制；股利會先被美國扣 **30%**。美國遺產稅對非美國人只有 **US$60,000** 免稅額，走複委託也躲不掉。

> **閱讀說明。** 本報告整合五份研究筆記。研究環境無法直接開啟多數官方網頁，包括金管會、財政部、IBKR 與 Alpaca 文件、LINE Biz 等，所以許多事實來自搜尋引擎對官方頁面的摘要，不是逐頁讀完全文。能完整讀到的主要是 Anthropic 的價格頁與使用政策、Claude Code 文件，以及幾個 GitHub 專案。標 **※** 的數字或條件，表示來自搜尋摘要、第三方整理，或來源之間互相矛盾，**動用真錢前請到官方頁面核對**。24 小時交易的進度一律分成「已上線／已核准／已提案」三種狀態。所有台灣時間都由美東時間經 Python `zoneinfo` 換算。本報告只是資訊整理，**不構成投資、法律或稅務建議**。

## IBKR 是唯一資格、API、夜盤都有證據的海外券商

如果目標是「台灣居民、官方 API、能跑 24 小時」，IBKR 是目前證據最完整的選擇。多篇 2026 年的台灣開戶教學都確認可以線上開戶，個人帳戶**沒有最低入金** ([市場先生](https://rich01.com/ib-interactivebrokers-open/))。IBKR 官方說明，帳戶由哪個 IBKR 法人承接，原則上依居住國決定，可以從 Activity Statement 頂端確認 ([IBKR Knowledge Base](https://ibkb.interactivebrokers.com/es/node/1000))。台灣帳戶由美國的 Interactive Brokers LLC 承接，只是第三方的推論 ([penchan.co](https://penchan.co/en/market/us-stock/ibkr-open-account/))。這點很重要，因為 SIPC 保障只適用美國實體。API 有兩條路。第一條是 TWS API，支援 Python 3.11 以上，但需要「已入金的 IBKR Pro 帳戶」，而且 TWS 或 IB Gateway 必須一直開著 ([IBKR TWS API 文件](https://www.interactivebrokers.com/campus/ibkr-api-page/twsapi-doc/))。第二條是 Web API，但散戶只能透過一支叫 Client Portal Gateway 的 Java 小程式驗證身分 ([IBKR Trading Web API](https://www.interactivebrokers.com/campus/ibkr-api-page/web-api-trading/))。Web API 的 session 只要 5 分鐘沒有請求就會逾時，官方建議每分鐘呼叫一次 `/tickle`，而且 session 最長 24 小時 ([IBKR Authentication FAQ](https://www.interactivebrokers.com/docs/web-api/authentication/faq))。

24 小時無人值守最大的痛點是 2FA。IB Gateway 每天自動重啟時可以沿用原本的 session，不用重新驗證。但大約每週一次（美東週日凌晨重置後）會強制完整登入，**必須在 IBKR Mobile 上按推播確認**。IBC 這類自動化工具能處理每天的重啟，卻刻意不去繞過這道手續 ([nautilus_trader issue #5069](https://github.com/nautechsystems/nautilus_trader/issues/5069)；[ibc2](https://pypi.org/project/ibc2/0.1.0/))。因此系統必須內建「Gateway 斷線，請去手機確認」的 LINE 推播。除此之外，IBKR 的技術條件都很充足。TWS API 預設上限是每秒 50 個請求 ([IBKR Pacing](https://www.interactivebrokers.com/docs/tws-api/doc/pacing-limitations/introduction))。夜盤下單只要在 Order 加上 `includeOvernight=True`，交易所保持 `SMART` 就能同時涵蓋日盤和夜盤 ([IBKR Overnight API](https://www.interactivebrokers.com/docs/tws-api/doc/orders/place-order/trading-the-overnight-session))。佣金部分，階梯式每股 0.0035 美元、每筆最低 0.35 美元；固定式每股 0.005 美元、每筆最低 1 美元 ※ ([Grenade](https://grenade.tw/blog/interactive-brokers-tutorial/))。有一個容易漏掉的設定：IBKR 預設把所有用戶歸為**專業（Professional）身分**，個人必須自己改成 Non-Professional，行情費用才會便宜。另外，TWS 畫面上免費的資料，不一定能透過 API 取得 ([IBKR Market Data Subscriptions](https://ibkrcampus.com/ibkr-api-page/market-data-subscriptions/))。

Alpaca 走的是另一個極端。它是對機器人最友善的券商：用 API key 驗證，不需要常駐閘道，也沒有每週 2FA。模擬交易免費，程式裡設 `TradingClient(paper=True)` 就行 ([alpaca-py 文件](https://docs.alpaca.markets/docs/alpaca-py-trading-api))。2026 年初起，Trading API 支援 24/5 交易，時段是美東週日 20:00 到週五 20:00 ([Alpaca Blog](https://alpaca.markets/blog/introducing-stocks-24_5-overnight-with-alpaca-trading-api/))。每個帳戶預設每分鐘 200 個請求 ([Alpaca Support](https://alpaca.markets/support/usage-limit-api-calls))，透過 API 交易美股不收佣金 ([Alpaca Support](https://alpaca.markets/support/individuals))。問題在資格。官方的可開戶國家頁沒有列出名單，只請用戶寫信問客服 ([Alpaca 可用國家](https://alpaca.markets/support/countries-alpaca-is-available))。另一份官方指南寫明，稅籍國如果不在下拉清單裡，**只能用模擬交易** ([Alpaca Learn](https://alpaca.markets/learn/connect-to-alpaca-api))。截至 2026-10，沒有查到任何台灣用戶成功開實盤的紀錄。比較好的做法是：先把 Alpaca 當開發沙盒，同時寫信問清楚。

其他選項都各有硬傷。嘉信國際（Schwab International）台灣可以開戶 ([Exiap](https://exiap.hk/guides/open-charles-schwab-account))，但查不到官方說法確認國際帳戶能用 Trader API。就算能用，refresh token **7 天就過期，而且無法用程式續期**，等於每週都要人工重新登入 ([tda_to_schwab](https://github.com/48n116w/tda_to_schwab))。第一證券（Firstrade）在台灣很普及，但**沒有官方 API**，只有逆向工程做出的 `firstrade-api` 套件，作者自己都寫「use at your own risk」 ([GitHub](https://github.com/MaxxRK/firstrade-api))。moomoo 的台灣帳戶據部落格說法落在美國的 Moomoo Financial Inc. ([米拉有料](https://mila4real.com/moomoo-taiwan-review-2025/))，它的 OpenAPI 需要常駐一支叫 OpenD 的閘道程式 ([Moomoo Help](https://www.moomoo.com/us/support/topic3_436))，但台灣帳戶能否用 API 實盤交易，查不到官方說法。此外，2026-05 中國證監會點名富途、老虎、長橋，展開為期兩年的整治 ([中央社](https://www.cna.com.tw/news/acn/202605220307.aspx))。對象雖然是中國大陸居民，但集團層級的業務調整風險仍值得留意。長橋（Longbridge）據部落格說法需要先有香港銀行帳戶 ([Vocus](https://vocus.cc/article/69240e65fd89780001892511))。Saxo 與 Tradier 的官方服務國家清單都沒有看到台灣 ([Saxo](https://www.help.saxo/hc/en-us/articles/10611416570269-Which-countries-are-serviced-by-Saxo)；[Tradier](https://support.tradier.com/kb/guide/en/permitted-and-blocked-countries-CLzSa0D1rf/Steps/4997916))。

### 複委託 API 只剩凱基與群益，也沒證實支援新開放的盤前盤後

如果你希望資金留在國內、受金管會監管，複委託的 API 選擇非常少。**凱基**在 2024-03 推出業界第一個「美股即時行情 API」，同時提供複委託下單、成交回報與查詢，新舊客戶都免費，官方文件以 C# 為主 ([凱基公告](https://www.kgi.com.tw/zh-tw/product-market/news-and-announcement/announcement/announcement-detail?id=2fc401a0c12a41108f59d18e27d0300a)；[鉅亨網](https://news.cnyes.com/news/id/5485188))。**群益**官方表示，同一套 API 就能串接國內證期、海外期權以及複委託，但**只能在 Windows 上執行**，雲端部署得另開 Windows 主機 ([群益 API](https://www.capital.com.tw/campaign/stock/API/))。永豐 Shioaji 與富邦 Neo API 的官方文件，只涵蓋台股與國內期貨 ([Shioaji](https://sinotrade.github.io/zh/)；[富邦 TradeAPI](https://www.fbs.com.tw/TradeAPI/en/docs/market-data/intro/))。複委託手續費 2026 年已降到 0.06%–0.1%，但多半是限期或有條件的優惠，各來源數字也不一致 ※ ([stevenhongisme](https://stevenhongisme.com/securities_firms/sub-brokerage-intro/))。以一筆 1 萬美元的交易來算，0.08% 約是 8 美元。IBKR 固定式買 100 股約 1 美元，Alpaca 是 0。高頻小額交易的成本差距會被放大。

時段方面，券商公會在 2026-07 底核准複委託交易美股盤前、盤後。兆豐最早開放，國泰從 9/30、富邦從 10/1 開始提供，玉山 10 月中旬上線；群益、凱基、永豐還在規劃 ([工商時報](https://www.ctee.com.tw/news/20260921700106-439901)；[中央社](https://www.cna.com.tw/news/afe/202609280032.aspx)；[蕃新聞](https://n.yam.com/Article/20261015423306))。**複委託夜盤尚未開放**，業者說跨日交割與資金入帳的系統難度很高。截至 2026-10，沒有任何一家券商公告「API 下單」和「盤前盤後」可以同時使用。凱基與群益的 API 是否支援新時段，必須直接問券商。

## 免費即時報價只看得到約 4% 成交量，推播給別人就算轉發

挑資料源之前，先弄懂「即時」的意思。Alpaca 免費方案的即時資料「只代表 IEX 交易所上的成交」，完整的 SIP（各交易所彙總的報價與成交）要付費 ([Alpaca Market Data FAQ](https://docs.alpaca.markets/us/docs/market-data-faq))。IEX 自己公布，2026 年第二季它只占美股總成交量（含場外）的 **3.8%** ([IEX](https://www.iex.io/news))。Twelve Data 也承認，它預設的美股即時資料大約只涵蓋全市場交易的 5% ([Twelve Data](https://support.twelvedata.com/en/articles/9935903-us-equities-market-data))。這代表免費 IEX 資料拿來做「價格突破」觸發，在熱門大型股上還堪用；但拿來做「成交量暴增」觸發，**看到的只是二十幾分之一的真實量**，判斷會失真。

授權問題比價格更容易被忽略。交易所對「非專業用戶」的定義是：未向 SEC 等機關註冊的自然人，帳戶用本人名義，資料只供個人、非商業用途 ([NYSE Market Data Policy](https://www.nyse.com/publicdocs/nyse/data/NYSE_Market_Data_Complete_Policy_Package.pdf))。Massive 的條款寫明，個人方案的資料「僅供顯示使用」 ([Massive Terms](https://massive.com/legal/market-data-terms-of-service))。它的知識庫也說，只要把資料給你自己以外的人看，包括測試者、同事，**開發期間也算**，就需要 Business 方案 ([Massive KB](https://massive.com/knowledge-base/article/which-plan-do-i-need-to-show-massive-data-in-my-app))，月費從 $499 起 ([Massive Business](https://massive.com/business-stocks))。Tiingo 的轉發授權另外賣 $250 或 $500/月 ([Tiingo IEX](https://www.tiingo.com/products/iex-api))。沒有任何資料商明文討論「推播到我自己的聊天軟體」這種情況。合理的解讀是：只推給自己的 LINE 帳號屬於個人顯示；拉進 LINE 群組、分享給家人或朋友，就是轉發。比較穩妥的做法是推送「AAPL 跌破 200 日線，成交量為均量 3 倍」這類衍生文字警示，而不是原始報價串流。不過衍生數值是否也受條款約束，仍要逐家確認。

新聞與公告可以做到幾乎免費。SEC EDGAR 允許每秒最多 10 個請求 ([SEC](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data))，submissions API 從公告發布到可查詢，通常**不到 1 秒** ([SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces))，偵測 8-K、Form 4 這類申報綽綽有餘。Alpaca News API 的內容來自 Benzinga，提供 REST 與 WebSocket，任何方案都能免費使用，只受方案的頻率限制 ([Alpaca 即時新聞](https://docs.alpaca.markets/us/docs/streaming-real-time-news)；[Alpaca Blog](https://alpaca.markets/blog/introducing-news-api-for-real-time-fiancial-news/))。Finnhub 免費層提供公司新聞與財報日曆，經濟日曆則要付費 ([Finnhub API](https://finnhub.io/docs/api/market-news))。如果想直接買 Benzinga，透過 Massive 加購的個人方案從 $99/月起 ※ ([Massive × Benzinga](https://massive.com/partners/benzinga))。總經事件不必花錢買日曆 API，直接把 BLS 公布的發布時程寫進設定檔就好 ([BLS 2026](https://www.bls.gov/schedule/2026/))。

## Claude 只在觸發時出場，月費約 US$10 這個量級

**MCP 適合隨手查詢，不適合當 24 小時監控器。** Alpaca 有官方的 `alpacahq/alpaca-mcp-server` v2，可以下市價、限價、停損、追蹤停損等真實訂單。它預設用模擬帳戶（`ALPACA_PAPER_TRADE=true`），也能用 `ALPACA_TOOLSETS` 只開放唯讀的工具組。但 README 特別警告：這個套件沒有內建遠端驗證，**不要把它連同 API key 一起暴露到公開網路**，只能在本機以 stdio 方式執行 ([Alpaca MCP README](https://github.com/alpacahq/alpaca-mcp-server))。IBKR 在 2026-07-28 推出官方 MCP 連接器，用戶透過 IBKR 自己的登入畫面授權單一帳戶 ([IBKR 新聞稿](https://www.interactivebrokers.com/en/index.php?f=78687))。第三方說法是 AI 只會草擬「AI Instructions」，用戶要在 IBKR 介面裡按 Review & Submit 才會送出 ([StockBrokers.com](https://www.stockbrokers.com/guides/ai-agent-brokers))，這點沒有在 IBKR 官方頁面上證實。社群做的 IBKR MCP 多半還在 alpha 階段 ([Glama](https://glama.ai/mcp/servers/@code-rabi/interactive-brokers-mcp/blob/dc2095c53552b7379015dbba7a6c8ebc858032e7/README.md))。資料端的 MCP 方面，Massive 有官方 `mcp_massive`，標示為 experimental ([GitHub](https://github.com/massive-com/mcp_massive))；Twelve Data 有官方代管的 MCP 服務 ([GitHub](https://github.com/twelvedata/mcp))。Alpha Vantage 的狀況有矛盾：有一個自稱官方的倉庫 `alphavantage/alpha_vantage_mcp` ([GitHub](https://github.com/alphavantage/alpha_vantage_mcp))，但也有目錄網站把同一個服務指向個人帳號 ([mcpservers.org](https://mcpservers.org/servers/calvernaz/alphavantage))，是否為官方仍待確認 ※。結論是：MCP 適合你在 Claude Desktop 或 Claude Code 裡隨手提問；真正 24 小時跑的監控程式，應該直接呼叫 REST 或 WebSocket。

**要長時間無人值守，就用 Messages API，自己擁有整個迴圈。** Claude Code 的排程功能不適合當即時監控：雲端 Routines 最短間隔 1 小時，`/loop` 這類 session 內的循環任務 7 天後自動失效，排程最多會延遲 30 分鐘，錯過的觸發也不會補跑 ([Claude Code 排程文件](https://code.claude.com/docs/en/scheduled-tasks))。這些功能拿來產生每日摘要很合適，當監控器就不行。自動化程式必須使用 Console 發的 API key，不能用 claude.ai 的訂閱登入 ([Agent SDK 文件](https://code.claude.com/docs/en/agent-sdk/overview))。如果用無頭模式的 `claude -p --bare`，還可以加 `--max-budget-usd` 設定花費上限 ([Headless 文件](https://code.claude.com/docs/en/headless))。

價格來自 Anthropic 官方價格頁，於 2026-10-17 直接讀取 ([Anthropic Pricing](https://platform.claude.com/docs/en/about-claude/pricing))。同一頁還有幾個影響預算的細節。Batch API 打五折，但屬於非同步處理，只適合盤前摘要這類不急的工作。內建的網頁搜尋工具每 1,000 次收 $10，每次分析都搜一次，每月就多出約 $15。Claude 4.7 之後的新 tokenizer，同樣的文字大約多算 30% 的 token。指定只在美國推論（US-only）要乘以 1.1 倍。思考過程的 token 一律按輸出計費。另外，Opus 5.5 的思考功能無法關閉，`temperature` 也不能設定，Sonnet 5.5 與 Haiku 5.5 則不接受非預設的取樣參數。所以**輸出的穩定性要靠程式來保證**：用結構化輸出（JSON schema）加上程式驗證，不能指望把溫度調成 0。實務上，用 Haiku 5.5 做第一層分流，只把高嚴重度的事件交給 Sonnet 5.5 深入分析（例如每天 10 次），基本費用約 US$7.5/月，加上思考 token，大約 US$10。新聞由程式自己抓好再餵給模型，不要讓模型自己上網搜尋。

**政策和實證都指向同一個設計。** Anthropic 使用政策的新版 **2026-11-12 生效**。新版把「針對特定證券的個人化買賣建議」列為高風險用途，要求有合格的人實質審查，並告知對方內容由 AI 產生。但它明確排除兩種情況：內部的研究、摘要、分析，以及「執行一個人已經做好的決定，或套用模型不做判斷的固定規則」 ([Anthropic Usage Policy](https://www.anthropic.com/legal/aup))。自己用、由你本人最後確認的工具，落在排除範圍內。如果把同一個 bot 開放給別人使用，性質就變成「給他人的建議」，也可能牽涉台灣與美國的投資顧問執照問題（本研究未深入查證）。實戰數據也不支持讓 LLM 自主交易。Alpha Arena 第一季用真錢比賽，Claude Sonnet 4.5 的 1 萬美元最後剩 **5,799 美元** ([Forklog](https://forklog.com/en/four-out-of-six-ai-models-suffer-losses-in-trading-tournament/))。KDD 2026 的 FINSABER 研究發現，拉長到二十年回測後，LLM 策略原本報告的優勢明顯消失：多頭時太保守，空頭時又因風控不足而虧損放大 ([arXiv 2505.07078](https://arxiv.org/abs/2505.07078))。另一篇研究 "The Alpha Illusion" 則指出，扣掉交易成本後，毛報酬經常變成淨虧損 ([alphaXiv](https://www.alphaxiv.org/abs/2605.16895))。Claude 的價值在於解釋「為什麼動」，而不是預測「接下來會怎麼動」。

**風控要把 LLM 隔離在下單路徑之外。** Anthropic 自己承認，提示注入（prompt injection）「還遠遠沒有解決」 ([Anthropic](https://www.anthropic.com/research/prompt-injection-defenses))。新聞稿、公告、網頁都可能夾帶惡意指令，因此系統提示要明說：工具回傳的內容一律是不可信的資料，不能當成指令 ([Claude 文件](https://platform.claude.com/docs/en/docs/mitigating-jailbreaks-prompt-injections))。OWASP 也建議，把讀取不可信內容的流程和擁有寫入權限的流程放在不同 session ([OWASP MCP Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/MCP_Security_Cheat_Sheet.html))。落實到這個系統，就是「兩把鑰匙」：負責讀新聞的 Claude 完全沒有交易工具；下單由一段普通程式執行，而且只在收到 LINE 確認之後才動作。下單前，程式要重新報價，並檢查標的白名單、價格偏離幅度、單筆與單日金額上限、每日最多筆數，以及是否只用限價單。

**LINE 的額度很緊，但回覆訊息不計費。** 台灣 LINE 官方帳號目前的方案如下 ※ ([LINE Biz TW](https://tw.linebiz.com/column/LINEOA-2026-Price-Plan/))：輕用量 NT$0、每月 200 則，不能加購；中用量 NT$800、3,000 則，不能加購，**11/1 起漲為 NT$1,000**；高用量 NT$1,200、6,000 則，**11/1 起漲為 NT$1,400**，加購每則 NT$0.2 起。有第三方指出這些價格未稅，尚未證實。回覆訊息不計入額度 ([LINE Developers](https://developers.line.biz/en/tips/2026/05/28/how-to-count-messages/))。推播依收件人數計算，同一個請求裡塞幾個訊息物件都只算一次 ([LINE Messaging API Pricing](https://developers.line.biz/en/docs/messaging-api/pricing/))。快速回覆最多可放 13 個按鈕，可以掛 postback 動作 ([Quick Reply](https://developers.line.biz/en/docs/messaging-api/using-quick-reply/))。postback 事件會帶 replyToken，所以「確認下單」之後的回覆是免費的 ([Actions](https://developers.line.biz/en/docs/messaging-api/actions/))。replyToken 的有效期，次級來源有 30 秒和 1 分鐘兩種說法 ※。Telegram bot 則完全免費，只有頻率限制 ([Telegram Bot FAQ](https://core.telegram.org/bots/faq))。你現有的 ChatGPT-Line-Bot 是 Flask 的 `/callback` 加 line-bot-sdk 2.4.1 與 MongoDB，目前只處理 `MessageEvent`，也只用 `reply_message`。要接上這套系統，需要新增 `PostbackEvent` 處理、主動推播的發送端，以及一個獨立的 Claude 模組；現有呼叫 OpenAI 的 `OpenAIModel` 路徑不必更動。

## 自行開戶不違法，但保障、報稅與遺產稅都要自己扛

**台灣法規管的是「招攬」，不是「開戶」。** 金管會 2018 年的新聞稿說明，未經許可的證券商在台招攬國人到國外開戶，違反證交法第 44 條，依第 175 條可處 2 年以下有期徒刑，或科新臺幣 180 萬元以下罰金。同一則新聞稿也提醒投資人，透過非法管道交易，發生糾紛時「無法獲得保障」 ([金管會 2018-04-12](https://www.fsc.gov.tw/ch/home.jsp?id=96&parentpath=0%2C2&mcustomize=news_view.jsp&dataserno=201804120002&aplistdn=ou%3Dnews%2Cou%3Dmultisite%2Cou%3Dchinese%2Cou%3Dap_root%2Co%3Dfsc%2Cc%3Dtw&dtable=News))。2024-12 與 2026-09 金管會兩度重申，未經核准的境外機構不得在台提供金融服務 ([中央社](https://www.cna.com.tw/news/afe/202412240363.aspx)；[工商時報](https://www.ctee.com.tw/news/20260901702090-430301))。2024–2026 年**查無**金管會點名處分 IBKR、Firstrade、moomoo 的公開紀錄。但「查無」不等於「沒有」。投資人自行開戶沒有刑責條文，代價是出了事不能找金管會或評議中心。複委託的優勢正好在這裡：受金管會監管；2024 年起海外部位可以交給集保結算所保管，2025 年 4 月保管市值已破新臺幣 1,000 億元 ([鉅亨網](https://m.cnyes.com/news/id/5723193))；券商會提供報稅用的海外所得明細。金管會也研擬開放複委託外幣融資，最快 2027 年第二季上路 ([中央社](https://www.cna.com.tw/news/afe/202608250324.aspx))。海外的美國券商則有 SIPC 保障，每位客戶上限 US$500,000，其中現金 US$250,000，**不要求美國居住或國籍** ([SIPC FAQ](https://Sipc.org/for-investors/investor-faqs))。但 SIPC 只在券商倒閉時補回遺失的資產，不保障市場跌價。投保中心的保護基金是否涵蓋複委託的海外部位，查不到官方說明，坊間流傳的數字也沒有經過驗證。

**美國的交易規則鬆綁了，操縱的紅線沒有變。** 2026-04-14，SEC 核准 FINRA 修正 Rule 4210。FINRA Regulatory Notice 26-10 宣布，**取消 Pattern Day Trader 規則與 US$25,000 最低權益要求**，改成依盤中曝險計算保證金，2026-06-04 生效，券商最晚可以延到 **2027-10-20** 才導入 ([FINRA RN 26-10](https://www.finra.org/rules-guidance/notices/26-10))。IBKR 在 6/4 就實施了 ([Traders Magazine](https://www.tradersmagazine.com/featured_articles/regulators-end-pdt-rule/))，嘉信從 6/8 起不再計算當沖次數 ([Schwab](https://www.schwab.com/learn/story/schwab-changes-rules-around-day-trading))。但現金帳戶仍受 T+1 交割限制，程式也不該假設每家券商都已經改制。台灣方面，沒有找到專門規範個人用 API 交易美股的法規。真正的紅線在美國的反操縱規定。幌騙（spoofing）與分層掛單（layering），是指下單時就打算在成交前撤單、製造假的買賣興趣，SEC 依 Exchange Act §9(a)(2)、§10(b) 與 Rule 10b-5 追訴，曾有案件判處 750 萬美元民事罰款 ([SEC LR-25427](https://www.sec.gov/litigation/litreleases/2022/lr25427.htm))。境外交易者透過美國券商下單也照樣被追訴，例如 Avalon 案 ([Mondo Visione](https://mondovisione.com/news/sec-wins-jury-trial-in-layering-manipulative-trading-case-20191112/))。程式應該為每一筆委託記下理由，避免大量下單又大量撤單。

**台灣稅：所得達 100 萬元就全額計入，損失不能跨年扣抵。** 美股的價差與股利都屬海外所得，不併入綜所稅，改適用最低稅負制。全戶（本人、配偶、受扶養親屬）海外所得合計達新臺幣 **100 萬元**，就要**全額**計入基本所得額，不是只算超過的部分 ([udn／國稅局](https://udn.com/news/story/7243/9367169))。基本所得額的扣除額在 113、114 年度都是 750 萬元，超過的部分課 20%，再和一般所得稅比較，取高者 ([財政部稅務入口網](https://www.etax.nat.gov.tw/etwmain/tax-info/understanding/tax-saving-manual/national/individual-income-tax/6xKrvGR))。115 年度的扣除額，次級來源說財政部公告維持 750 萬元 ※ ([行政院公報](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg031224/ch04/type3/gov30/num12/Eg.pdf))。財產交易所得按**交割日所屬年度**認列，錢沒有匯回台灣也要申報。海外財產交易損失**只能扣抵同年度**的海外財產交易所得，不能遞延到以後年度。南區國稅局就有納稅人拿前一年的損失來扣抵，結果被補稅又罰款 ([udn](https://udn.com/news/story/7243/9493821))。漏報的罰鍰，已申報者最高是漏稅額的 2 倍，未申報者最高 3 倍（2022 年資料） ([KPMG](https://kpmg.com/tw/zh/home/media/press-releases/2022/05/income-basic-tax-review.html))。程式交易的周轉率高，已實現利得很容易一年就超過 100 萬元，所以交割日、成本、手續費、匯率都要逐筆記錄。美國沒有加入 CRS，台美 FATCA 又是不對等的 Model 2 ([regfollower](https://regfollower.com/us-taiwan-signed-foreign-account-tax-compliance-act-fatca-agreement/))，IRS 不會自動把你的帳戶資料交給台灣。但這不會改變你的申報義務。

**美國稅：股利扣 30%，遺產稅才是大坑。** 提交 W-8BEN 之後，美國來源的股利按 30% 扣繳 ([IRS W-8BEN 說明](https://www.irs.gov/pub/irs-pdf/iw8ben.pdf))。一年在美國停留不到 183 天的非居民，股票資本利得一般不課美國稅 ([IRS](https://www.irs.gov/individuals/international-taxpayers/the-taxation-of-capital-gains-of-nonresident-students-scholars-and-employees-of-foreign-governments))。台美避免雙重課稅法案方面，眾議院在 2025-01-15 以 423 比 1 通過 H.R. 33 ([RSM](https://rsmus.com/insights/tax-alerts/2025/house-passes-us-taiwan-double-tax-relief-act.html))。法案通過後，股利扣繳可降到 15% ([CRS IF10256](https://www.congress.gov/crs_external_products/IF/PDF/IF10256/IF10256.35.pdf))，但參議院版的 S. 199 截至 2026-10 **仍未通過**，駐美代表 7 月時表示希望年內過關 ([中央社](https://www.cna.com.tw/news/aipl/202607110011.aspx))。遺產稅才是最容易被低估的部分。非美國人持有的美國股票，免稅額只有 **US$60,000**，超過的部分最高課 40%，遺產執行人要在死亡後 9 個月內申報 Form 706-NA ([beancount.io](https://beancount.io/zh/blog/2026/05/16/form-706-na-nonresident-alien-estate-tax-60000-exemption-us-situs-property-foreign-investors-firpta-treaty-relief-guide))。**透過複委託持有一樣適用** ([今周刊](https://www.businesstoday.com.tw/article/category/183022/post/202601130002/))。海外券商帳戶的繼承人，通常還要先取得 IRS Form 5173 才能領出資產 ([WealthManagement](https://www.wealthmanagement.com/estate-planning/mastering-the-transfer-certificate))。另外，賣出公開交易合夥（PTP）時，券商會就**成交總額**扣 10% ([26 CFR §1.1446(f)-4](https://www.law.cornell.edu/cfr/text/26/1.1446%28f%29-4))，觀察清單應該直接排除 PTP 和 MLP。資金匯出方面，個人每年結匯在 500 萬美元以內可以直接向銀行申報，單筆 50 萬美元以上要附證明文件 ※ ([中央銀行](https://www.cbc.gov.tw/public/Attachment/811149322771.pdf))。電匯若選全額到行（OUR），台灣端約要新臺幣 800–1,200 元；不選的話，每經過一家中間行會被扣約 US$18–25 ([beurlife](https://www.beurlife.com/2026/05/best_way_foreign_remittance.html))。

## 結論

這個專案真正的瓶頸不在 AI，而在三種「摩擦」。第一是**驗證摩擦**：資格確定的券商（IBKR）每週要人按一次手機，免手動的券商（Alpaca）資格卻不確定。所以「24 小時」實際上是「24 小時，加上每週一次需要你」，LINE 推播的第一個用途，其實是叫你去手機按確認。第二是**資料真實性**：免費資料只看得到一小部分市場，12/6 之前的夜盤又分散在各個 ATS，Claude 讀到的「盤勢」未必就是真實市場。12/6 SIP 改制是一個已排定的斷點，盤別、交易日、資料來源都必須寫成設定，不能寫死在程式裡。第三是**責任轉移**：選海外券商、自行開戶，等於把糾紛處理、報稅計算、遺產規劃從制度轉回你自己身上。這些成本，很可能比 Claude 的月費高出好幾倍。

反過來看，Anthropic 的使用政策、LLM 交易的實證研究、還有 prompt injection 的風險，三方面都指向同一種架構：規則由程式決定，解釋交給 Claude，最後由你拍板。這不只是保守的選擇，也是成本最低、最容易稽核的選擇。在這個架構裡，Claude 每月約 US$10，是預算中最小的一項；SIP 行情費和 LINE 中用量方案都跟它同一個量級，甚至更高。

## 實務建議：先模擬、再小額實盤的起步組合

建議分兩個階段，並在程式裡留一層「券商轉接介面」，讓第一階段寫的監控與分析程式碼，到第二階段換券商時不必重寫。

| 層 | 第一階段：模擬，幾乎零成本 | 第二階段：小額實盤 |
|---|---|---|
| 券商 | Alpaca 模擬帳戶，同時寫信問 support：台灣稅籍能否開實盤 | IBKR（IB Gateway + IBC，用 Docker 跑），先用 IBKR 模擬帳戶跑兩週；想走國內就問凱基複委託 API 能否用 Python、支不支援盤前盤後 |
| 行情 | Alpaca Basic：IEX 即時做價格觸發，延遲的 SIP 做成交量確認 | IBKR Non-Pro 套組 $10（佣金滿額免收 ※）+ 串流 $4.50；或 Alpaca Algo Trader Plus $99 |
| 夜盤資料 | 先不做，或用 Alpaca 衍生 overnight 資料 | IBKR 夜盤資料免費 |
| 新聞與公告 | Alpaca News API + SEC EDGAR + Finnhub 免費層 | 同左；不夠時再考慮 Benzinga（$99 起 ※） |
| 分析 | `claude-haiku-5-5` 分流，`claude-sonnet-5-5` 深入分析，約 US$10/月 | 同左；盤前摘要改用 Batch API 打五折 |
| 通知 | LINE 輕用量 200 則，加上免費的回覆 | 不夠時升中用量（11/1 起 NT$1,000 ※），或把高頻警示分流到 Telegram |
| 主機 | 自己的電腦或小型 VM | 美東區小型 VM（價格未查證） |

架構上，各部分的分工要很清楚。**監控程式**是純 Python 的常駐程序，不呼叫任何 LLM。它訂閱 WebSocket 報價，依規則判斷是否觸發：價格突破、相對前一日收盤的漲跌幅、成交量（要有 SIP 才準）、EDGAR 的 8-K 或 Form 4。交易時段與假日表用 `America/New_York` 存在設定檔，另外要能偵測報價停滯，並定時發出心跳。觸發後，程式把報價快照、近幾小時的 Alpaca 與 Finnhub 新聞、相關的 EDGAR 公告打包，交給 **Claude 分析**。Haiku 5.5 先判斷事件的嚴重度，高嚴重度的再交給 Sonnet 5.5。輸出固定為 JSON，欄位包括摘要、原因、來源連結、嚴重度，以及可選的下單提案（代號、方向、股數、限價）。系統提示要寫明新聞內容是不可信的資料。負責分析的模型**不接任何交易工具**。

**LINE 端**把同一事件的多則泡泡訊息合成一次推播，並標註「AI 產生的分析，非投資建議」，下方附上快速回覆按鈕：確認下單、略過、詳情。每個按鈕都是 postback，帶一個只能用一次的提案編號。webhook 收到後，先驗證簽章與 userId 白名單，再交給**下單執行器**。執行器是普通程式，它會重新報價，然後驗證：標的在白名單內、限價離現價在 ±X% 以內、不超過單筆與單日金額上限、不超過每日筆數、只用限價單、不用融資與選擇權、排除 PTP、市場正在交易中、提案沒有超過約 5 分鐘的有效期。全部通過才下限價單，再用免費的 reply 回報結果。所有觸發、prompt、模型 ID、`request_id`、token 用量、驗證結果、你的確認、券商的委託編號與成交，都寫進現有的 MongoDB。這份紀錄同時就是報稅底稿。監控程式要和 Flask webhook 分開，作為獨立的常駐程序執行，因為它必須一直維持 WebSocket 連線。

**LINE 額度要這樣分配。** 免費的 200 則，平均一天約 6 則。建議把每天兩則摘要固定下來：台灣晚上盤前一則、清晨收盤後一則，一個月 60 則。IBKR 每週 2FA 提醒預留 4–5 則。剩下約 135 則留給即時警示，約每天 4.5 則，在程式裡設硬性上限，只推高嚴重度的事件。「詳情」按鈕一律用 reply 回覆，不吃額度。成交通知要算進額度。月底額度快用完時，自動降級成「只發摘要」，或改送 Telegram。如果確定每月需要超過 200 則，再升級中用量方案。

動用真錢之前，至少確認下面幾件事：

| 確認項目 | 要確認什麼 | 去哪裡確認 |
|---|---|---|
| 券商資格與承接實體 | Alpaca 台灣稅籍能否開實盤；IBKR 由哪個實體承接（決定 SIPC 是否適用）；moomoo 的 OpenAPI 能否實盤 | Alpaca support 回信、IBKR Activity Statement 頂端、moomoo 客服 |
